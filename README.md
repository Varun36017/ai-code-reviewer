# AI Code Reviewer & Learning Assistant

A Python project being developed to combine automated code checks
with AI-assisted reviews and beginner-friendly explanations.

## Project status

Under active development. The existing prototype is being rebuilt
to improve review reliability, usability, and project structure.

## Planned features

- Python code upload and syntax validation
- Automated checks combined with Gemini-assisted reviews
- Findings with severity, explanations, and source line references
- Suggested fixes with before-and-after comparisons
- Follow-up chat about code and review findings
- Downloadable review reports
- Evaluation using examples with known issues

## Development approach

Build and test locally, track changes with Git, and publish
progress through GitHub.
